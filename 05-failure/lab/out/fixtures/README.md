# Synthetic fixtures

Everything in this directory was generated by `tools/make_fixtures.py`
from a model. **None of it is a measurement.** It exists so the plotting
scripts in `tools/` can be run and checked on a machine with no Docker
and no k6, and for nothing else.

Every file starts with a `# SYNTHETIC` line, and every plotter prints a
warning when it reads one. Do not copy a number out of a chart drawn
from these files into any results table.

Regenerate them with:

    python3 tools/make_fixtures.py

Real output goes in `out/` itself, written by
`docker compose run --rm k6 run /scripts/... --out csv=/out/...`.
